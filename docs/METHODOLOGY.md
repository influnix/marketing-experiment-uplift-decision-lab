# 발송 정책을 판단하는 분석 방법

## 무작위 실험으로 평균 증분 효과 확인

무작위 배정은 이메일 발송에 배정된 집단과 비발송에 배정된 집단의 결과를 비교할 근거를 제공합니다. 분석은 최초 배정군으로 비교하는 ITT(Intention-to-Treat)를 사용합니다. 열람자만 비교하면 원래 구매 의향이 높았던 고객이 한쪽에 더 많이 포함될 수 있기 때문입니다.

합성 시연은 No E-Mail, Mens E-Mail, Womens E-Mail 세 군에 각각 1/3 확률로 독립 배정합니다. 배정군 순서대로 전환 확률은 0.10·0.16·0.13, 방문 확률은 0.20·0.26·0.23입니다. 전환과 방문은 같은 균등 난수로 생성해 전환이 방문에 포함되도록 했습니다. 전환 시 매출은 평균 50달러인 지수분포에서 뽑아 센트 단위로 반올림하고, 미전환 시 0으로 둡니다. 이 값들은 합성 설계 가정입니다.

## 평균 효과를 타기팅 근거로 바꾸려면

전체 평균이 양수여도 고객군별 효과는 다를 수 있습니다. 먼저 사전에 정의한 고객군에서 차이를 살피고, 한 고객군에서만 유의하다는 이유로 효과의 차이를 단정하기 전에 군 사이의 차이 자체를 검정합니다. 작은 표본과 여러 비교는 발견을 불안정하게 만듭니다.

T-Learner는 발송과 비발송의 기대 반응을 각각 모델링하고 그 차이를 조건부 증분 효과(CATE)로 추정하는 방법입니다. 전환을 잘 예측하는 모델도 발송으로 반응이 달라질 고객을 잘 찾는지는 따로 검증해야 합니다. 같은 고객이 두 행동을 모두 경험한 결과는 관측할 수 없으므로, 실험의 독립 평가 표본에서 그룹별 예측 효과와 관측된 인과 대비를 대조하고 정책 가치도 평가합니다. 이 저장소의 대시보드에는 고객별 Uplift 모델이나 타기팅 정책 실행 기능이 없습니다.

## 고정 정책을 같은 실험에서 비교

합성 대시보드는 P0 전원 비발송, P1 전원 Mens 이메일, P2 전원 Womens 이메일, P3 세 행동의 균등 무작위를 비교합니다. 실험군 평균은 그 행동에 배정된 사람만으로 계산합니다. 반면 정책 가치는 실험 전체를 기준으로, 정책이 선택할 행동과 실제 실험 배정이 얼마나 일치하는지를 반영합니다.

정책이 관측 행동을 택할 확률을 `q(A)`, 배정 확률을 `1/3`이라 하면, 각 관측 결과 `Y`에 `q(A)/(1/3)`을 곱해 평균을 냅니다. 이것이 HT IPS(Horvitz–Thompson Inverse Propensity Scoring)입니다. 예를 들어 P1에서는 Mens 이메일로 배정된 결과에 가중치 3이 붙고 다른 행은 0입니다. P3에서는 가중치가 모두 1입니다. P0 대비 차이는 같은 실험 행의 두 정책 점수를 먼저 빼 공통 표본에서 생기는 공분산을 반영합니다.

독립 행 가정과 정규근사로 개별 95% 신뢰구간과 양측 p-value를 계산합니다. Holm 보정은 전환 대비 3개와 방문·매출 대비 6개를 별도 집합으로 처리합니다. 표에 표시되는 개별 CI는 다중 비교를 보정한 동시 신뢰구간이 아닙니다. 매출은 고객당 매출액이고, 전환·방문 수준은 %, 그 차이는 percentage point(%p)입니다.
